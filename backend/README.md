# TeamTrack — Backend

Express + MongoDB REST API for TeamTrack.

## Setup
1. `npm install`
2. Copy `.env.example` to `.env` and fill in your values
3. `npm start` (or `node server.js`)

## API Routes
- `/api/auth` — signup, login
- `/api/projects` — create, list, view, manage members
- `/api/tasks` — create, list, update, delete
